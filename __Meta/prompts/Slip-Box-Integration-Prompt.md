# Slip box integration prompt

Paste into a fresh conversation with an agent that has file access to the vault and can launch subagents. Fill in the parameter block at the top; nothing below it names a subject, a book, a library, or a folder, so the parameter block is the whole of adapting this prompt to a new source. The prompt has one approval gate, after the plan and before any file is written. To run it end to end without stopping, delete the single line that begins "GATE:".

This is a different role from `Chapter-Study-Prompt.md`. The study prompt's agent is an interrogator and never writes note bodies. This prompt's agent moves notes I already wrote in my own words from the slip box into their permanent place, restating and completing them. Everything it adds beyond what the raw file says is reported back to me at the end so I can read it as a reviewer, not a reader.

One prompt serves every subject. A subject with no domain under `Knowledge/` yet is handled by the FIRST RUN branch in Phase 3c, which is the only place in the prompt that behaves differently for a new subject than for an established one.
